# Roadmap

This file lists the planned releases of optimal-discretizer. Each milestone can have an implementation plan in
`docs/plans/`. An agent or a contributor can use the plan as the full task description. The PR that completes a
milestone sets its status to "Done" and its version in `pyproject.toml`.

## Milestones

| Version | Milestone | Plan | Needs | Status |
| --- | --- | --- | --- | --- |
| 0.1.0 | The first release that users can depend on: exact 1-D k-means discretization on PyPI, with wheels for each platform and a Lean proof of the optimum. | None | | Done |
| **1.0.0** | **Stable API.** No breaking change without a new MAJOR version. | None | 0.1.0 | Planned |
